# Anand Raj | Personal Portfolio

A minimalist, high-end personal portfolio website inspired by brutalist typography and modern interactive web design. Built from scratch without the use of complex frameworks to ensure maximum performance and total control over the DOM. 

**🌐 Live Site:** [https://Anandraj239.github.io](https://Anandraj239.github.io)

## ⚡ Features

- **Click-to-Enter Loader:** A custom, interactive loading screen that waits for user interaction before unveiling the website.
- **Brutalist Typography:** Uses bold, striking fonts (`Syne` and `JetBrains Mono`) for a distinct and memorable visual identity.
- **Interactive Project Showcase:** Features a custom mouse-following image preview effect when hovering over project listings.
- **Dynamic Styling:** Implements custom CSS noise overlays and micro-animations for a highly polished, premium feel.
- **Responsive Layout:** Designed to look exceptional on all devices, from ultra-wide desktop monitors to mobile screens. 

## 🛠️ Technologies Used 

- **HTML5:** Semantic, well-structured document foundation.
- **CSS3:** Custom variables, grid/flexbox layouts, noise effects, and smooth transitions/animations.
- **Vanilla JavaScript:** DOM manipulation, event handling, and mouse-following preview mechanics without heavy libraries.

## 🚀 Highlighted Projects

The portfolio showcases various projects spanning AI, Automation, and Development, including:
- **Hand Pose Visualizer:** An AI vision project built using Python and MediaPipe.
- **Arcade GitHub Profile:** Custom automated profile generation using GitHub Actions and SVG.
- **Daily Streak Bot:** Automation bot built with Python and Cron for maintaining consistent activity.

## 💻 Local Development

To run this project locally, simply clone the repository and open the `index.html` file in your preferred web browser, or use a local development server like VS Code's Live Server.

```bash
git clone https://github.com/Anandraj239/Anandraj239.github.io.git
cd Anandraj239.github.io
# Open index.html in your browser
```
